

## Endpoints principales

### Auth
- POST `/auth/login`
- POST `/auth/register`

### Productos
- GET `/productos`
- GET `/productos/:id`
- POST `/productos` (ADMIN)
- PUT `/productos/:id` (ADMIN)
- DELETE `/productos/:id` (ADMIN)

### Boletas
- POST `/boletas` (CLIENTE)
- GET `/boletas` (ADMIN / VENDEDOR)
- GET `/boletas/mias` (CLIENTE)
